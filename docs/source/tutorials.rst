Tutorials
=========

Choose an example. Each page shows the input, the run command and the results.
Comments beside the input lines explain their purpose.

Install the bundled examples once:

.. code-block:: bash

   nanoworks --install-examples

An existing examples directory is preserved. Use the inputs bundled with your
installed version; keep the selected engine and potentials installed.
